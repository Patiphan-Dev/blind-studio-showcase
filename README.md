# ม่านสตูดิโอ — เว็บโชว์สินค้าม่านม้วนและมู่ลี่ (เวอร์ชันตัวอย่าง)

เว็บไซต์แคตตาล็อกสินค้าตกแต่งช่องแสง (ม่านม้วน มู่ลี่ไม้ มู่ลี่อลูมิเนียม
ม่านปรับแสง มุ้งม้วนกันแมลง) พร้อมหน้าผลงานติดตั้ง หน้าติดต่อ และระบบหลังบ้าน
สำหรับเพิ่ม/แก้สินค้า ผลงาน และข้อความบนเว็บ

> ข้อมูล บริษัท สินค้า ราคา รูปภาพ และผลงานทั้งหมดในตอนนี้เป็น **ข้อมูลตัวอย่าง**
> แก้ให้เป็นข้อมูลจริงได้จากระบบหลังบ้าน

---

## เทคโนโลยี

| ส่วน | ใช้ |
| --- | --- |
| เว็บเฟรมเวิร์ก | Next.js 16 (App Router) + TypeScript |
| ดีไซน์ | Tailwind CSS v4 — สไตล์ Minimal / Swiss |
| ฐานข้อมูล + ล็อกอิน | Supabase (Postgres + Auth + RLS) |
| โฮสติ้ง | Vercel |

---

## การตั้งค่าเพื่อรันในเครื่อง

```bash
npm install
cp .env.example .env.local   # แล้วใส่ค่าจริงจาก Supabase
npm run dev
```

เปิด http://localhost:3000

ตัวแปรที่ต้องตั้ง (ดู `.env.example`):

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `NEXT_PUBLIC_SITE_URL`

## โครงสร้างโค้ด

```
src/
  app/(site)/       หน้าเว็บส่วนหน้าบ้าน (แรก, สินค้า, ผลงาน, เกี่ยวกับ, ติดต่อ)
  app/admin/        ระบบหลังบ้าน (ล็อกอิน + จัดการเนื้อหา)
  app/api/contact/  รับข้อมูลจากฟอร์มติดต่อ (มี rate limit + ตรวจข้อมูล)
  components/site/   ส่วนประกอบหน้าบ้าน
  components/admin/  ส่วนประกอบหลังบ้าน
  components/ui/     ปุ่ม/ฟิลด์/แท็ก ที่ใช้ซ้ำ
  lib/queries/      ฟังก์ชันดึงข้อมูลจากฐานข้อมูล
  lib/validation/   ตรวจความถูกต้องข้อมูลด้วย zod
  lib/supabase/     การเชื่อมต่อ Supabase (ฝั่ง client / server / proxy)
  types/            ชนิดข้อมูลกลาง
supabase-migrations/ ไฟล์ SQL สร้างตารางและ seed (อ้างอิง — ใช้ผ่าน Supabase แล้ว)
```

ฐานข้อมูลเปิด Row Level Security ทุกตาราง: คนทั่วไปเห็นเฉพาะรายการที่ตั้งค่า
"เผยแพร่" ส่วนการเพิ่ม/แก้/ลบ ทำได้เฉพาะบัญชีที่อยู่ในตาราง `admins`
