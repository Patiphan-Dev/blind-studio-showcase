# คู่มือใช้งานระบบหลังบ้าน (ฉบับมือใหม่)

ระบบหลังบ้านคือหน้าเว็บสำหรับ **เจ้าของเว็บ** ใช้เพิ่ม/แก้ไขข้อมูลที่แสดงบนหน้าเว็บจริง
โดยไม่ต้องยุ่งกับโค้ด

---

## 1. เข้าสู่ระบบ

1. เปิด `เว็บของคุณ/admin`
2. กรอกอีเมลและรหัสผ่านที่ได้รับ
3. กด**เข้าสู่ระบบ**

> เปลี่ยนรหัสผ่านครั้งแรกได้ที่ Supabase → Authentication → Users
> (หรือแจ้งผู้ดูแลระบบให้ตั้งให้)

ถ้าลืมรหัสผ่าน ให้ผู้ดูแลระบบตั้งรหัสใหม่ให้จาก Supabase

---

## 2. เมนูในระบบหลังบ้าน

| เมนู | ใช้ทำอะไร |
| --- | --- |
| **ภาพรวม** | ดูจำนวนสินค้า ผลงาน และข้อความติดต่อที่ยังไม่จัดการ |
| **สินค้า** | เพิ่ม / แก้ไข / ลบ สินค้า และตั้งว่าจะโชว์หรือซ่อน |
| **ผลงานติดตั้ง** | เพิ่ม / แก้ไข / ลบ ผลงานในหน้า Portfolio |
| **ข้อความติดต่อ** | อ่านข้อความที่ลูกค้าส่งผ่านฟอร์มหน้าติดต่อเรา |
| **ข้อความบนเว็บ** | แก้ชื่อแบรนด์ เบอร์โทร ที่อยู่ ข้อความหน้าแรก ข้อความ About ฯลฯ |

---

## 3. เพิ่มสินค้าใหม่

1. เมนู **สินค้า** → ปุ่ม **+ เพิ่มสินค้า**
2. กรอกข้อมูล:
   - **ชื่อสินค้า** — จำเป็น
   - **slug** — เว้นว่างได้ ระบบสร้างลิงก์ให้อัตโนมัติ
   - **หมวดหมู่** — เลือกจากรายการ
   - **คำโปรยสั้น** — ข้อความ 1–2 บรรทัดที่โชว์ใต้ชื่อสินค้าในหน้ารวม
   - **รายละเอียด** — คำอธิบายเต็มในหน้าสินค้า
   - **ช่วงราคา** — พิมพ์เป็นข้อความอิสระ เช่น `เริ่มต้น 1,200 บ./ตร.ม.`
   - **จุดเด่น** — พิมพ์ **บรรทัดละ 1 ข้อ**
   - **ลิงก์รูปภาพเพิ่มเติม** — ใส่ URL รูป **บรรทัดละ 1 อัน** (เว้นว่างได้ ระบบจะวาดภาพประกอบให้)
3. ติ๊ก **เผยแพร่บนเว็บ** เพื่อให้คนทั่วไปเห็น
4. ติ๊ก **ตั้งเป็นสินค้าแนะนำ** ถ้าอยากให้ขึ้นหน้าแรก
5. กด **บันทึกสินค้า**

### แก้ไข / ลบ สินค้า

- เมนู **สินค้า** → กด **แก้ไข** ที่แถวของสินค้านั้น
- แก้เสร็จกด **บันทึกการแก้ไข**
- ปุ่ม **ลบสินค้านี้** อยู่ล่างสุดของหน้าแก้ไข (ลบแล้วกู้คืนไม่ได้)

---

## 4. เพิ่มผลงานติดตั้ง

เมนู **ผลงานติดตั้ง** → **+ เพิ่มผลงาน** — วิธีกรอกเหมือนสินค้า มีเพิ่ม:

- **สถานที่ / พื้นที่** — เช่น `คอนโดย่านทองหล่อ กรุงเทพฯ`
- **เดือน/ปีที่ติดตั้ง** — เลือกจากปฏิทิน
- **สินค้าที่ใช้ในงานนี้** — พิมพ์บรรทัดละ 1 รายการ (โชว์เป็นแท็ก)

---

## 5. ข้อความติดต่อ

- ทุกครั้งที่ลูกค้าส่งฟอร์มหน้า **ติดต่อเรา** ข้อความจะเข้ามาที่เมนูนี้
- กด **ทำเครื่องหมายว่าจัดการแล้ว** เมื่อโทรกลับ/ตอบลูกค้าเรียบร้อย
- ตัวเลขสีส้มบนเมนูคือจำนวนข้อความที่ยังไม่จัดการ

---

## 6. แก้ข้อความ / ข้อมูลติดต่อบนเว็บ

เมนู **ข้อความบนเว็บ** แก้ได้ทั้งหน้าเดียว เช่น:

- ชื่อแบรนด์ / สโลแกน
- หัวข้อและคำโปรยหน้าแรก
- เนื้อหาหน้าเกี่ยวกับเรา
- เบอร์โทร อีเมล ที่อยู่ LINE Facebook Instagram เวลาทำการ
- คำค้นหาแผนที่ Google Maps (พิมพ์ชื่อสถานที่หรือพิกัด)

แก้เสร็จกด **บันทึกข้อความบนเว็บ** แล้วหน้าเว็บจริงจะอัปเดตทันที

---

## 7. ทำให้เว็บเป็นข้อมูลจริง (เช็กลิสต์)

- [ ] แก้ทุกช่องในเมนู **ข้อความบนเว็บ** ให้เป็นข้อมูลบริษัทจริง
- [ ] ลบสินค้าตัวอย่าง 9 รายการ แล้วเพิ่มสินค้าจริง
- [ ] ลบผลงานตัวอย่าง 4 รายการ แล้วเพิ่มผลงานจริง (พร้อมรูปจริง)
- [ ] เปลี่ยนรหัสผ่านบัญชีผู้ดูแล
- [ ] แจ้งผู้ดูแลระบบให้ลบข้อความ "เว็บตัวอย่าง" (แถบดำด้านบน + ข้อความท้ายเว็บ)
